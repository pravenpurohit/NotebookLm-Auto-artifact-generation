Format: The Debate (two hosts)

Host A argues for the dominant recommendation/conclusion found in the sources.
Host B challenges it using only counterpoints present in the sources.

Debate rules:
- Each side must cite specific evidence from the sources (mention source titles/sections verbally).
- 3 rounds: opening → cross-exam → closing.
- End with a neutral synthesis: what’s actually supported, what’s uncertain, what depends on context.
